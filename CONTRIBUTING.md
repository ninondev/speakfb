# Contributing

Pull requests are welcome.

Build with `make`. Run the speech test with `make test` on a Mac that meets the requirements in the README.
If transcription fails, include the error and your macOS version. Do not include private recordings or reports.

Before a pull request can be merged, read [CLA.md](CLA.md) and post this comment on the pull request:

> I have read the CLA and I agree to it.

Keep changes small. Explain what changed and what you tested.
